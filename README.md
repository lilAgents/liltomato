# lilTomato

A clean, fullscreen-capable Pomodoro focus timer with tasks, stats, ambient sound, and notifications. A free tool by [lilAgents](https://lilagents.com).

**Live version:** https://lilagents.com/tools/tomato/

This is the standalone, open-source build, a self-contained Astro site. The canonical hosted version is folded natively into the lilAgents website.

## Run locally

```
pnpm install
pnpm dev
pnpm build    # -> dist/
```

## Tech

Astro + Tailwind CSS + vanilla JS. 100% client-side (localStorage + Web Audio); no backend, no API keys.
